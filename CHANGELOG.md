# Changelog

## 0.1.0

- Initial library build.
- Added unified `AI(...)` dispatcher and `AIResponse`.
- Added providers for OpenAI, Anthropic, Google, xAI, Mistral, Groq, Cohere,
  Together, Perplexity, and DeepSeek.
- Added chat sessions, batch calls, fallback chains, comparison, async wrappers,
  cost tracking, env loading, retries, and custom provider registration.
